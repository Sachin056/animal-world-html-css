# 🐾 Animal World

Animal World is a simple and responsive website created using **HTML and CSS**.  
It provides information about different animals and their unique characteristics.

## 🌍 Features

- 🦁 Lion information
- 🐘 Elephant information
- 🐯 Tiger information
- 🐼 Panda information
- 🦌 Deer information
- 🦒 Giraffe information
- 📱 Responsive design
- 🧭 Navigation menu
- 🖼️ Animal images
- 🎨 Clean and simple user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
